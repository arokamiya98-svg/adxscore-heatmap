# 経済指標ボラティリティ・ランキング v1（XAUUSD H1）

> ボライベント縦線インジ構想の「注目イベント精査」＝実測の背骨。
> 主観の注目セットを実測で較正し、縦線の重み/色Tierの根拠にする。
> 実施: 2026-08-12 / メインおぱ

## 手法
- **イベント履歴**: MT5内蔵カレンダー → `data/bt/Econ_Calendar_US_History.csv`
  （`Econ_Calendar_History_Export_v1.mq5` 出力・USD・2024.01〜2026.12・10,738件・**サーバー時間**）
- **ボラ指標**: `ATR_Ratio_Timeseries_v1.csv` の `H1_ATR16` から Wilder 逆算で
  **単発 True Range を復元**: `TR[t] = 16·ATR16[t] − 15·ATR16[t-1]`（連続バーのみ）。
  平滑ATRだと単発爆発が1/16に薄まるため、生TRに戻すのが肝。
- **測定**: 各イベント発生時刻（サーバー時間＝価格と同一系＝較正不要）の hour を起点に
  窓 [0,+3h] の TR ピークを取り、全体中央値 `med=9.36 USD/h` で割った倍率。
- **測定窓**: 2024-01-02〜2026-07-02（ATR CSV 期間）。
- **ベースライン**: 全バーのランダム3h窓ピーク中央値 = **x1.53**。これを超えて初めて「イベントで動く」。

## 発見
1. **NFPが王**（中央値x3.3・x3超率64%＝ほぼ毎回動く）。あろさんの「NFP>CPI」感覚を実測が裏付け。
2. **CPI・FOMCが2番手タイ**（x2.7-2.8）。FOMCは最大x11.8＝サプライズ時の瞬間風速が全指標最大（テールが太い）。
3. **ISM製造業がほぼ平常時**（x1.7 vs ランダムx1.53）。習慣の4本柱の一角だがXAU的には針が振れない。ISM非製造業(x2.1)の方がマシ＝主観の実測補正。
4. **ラグ全部+0/+1h**＝サーバー時間直マッチで較正完璧。縦線の"危険窓"は発表〜+2h。

## Tier（縦線インジの重み/色に直結）
- **Tier S**（太線・濃）: NFP / CPI / FOMC金利
- **Tier A**（中）: PPI / 小売 / GDP / PCE / ADP / PMI速報
- **Tier B**（薄 or 外す候補）: ISM非製造業 / ISM製造業

## 留保
- H1粒度の単発TR（8:30ET発表はH1バーに収まる）。より細かい爆発は M15/M5 で要追試。
- N=20〜31（FOMC20）。十分だが決定打ではない。
- PMI速報は S&P Global の flash と final を分離していない（同名のため）。要分割で純度UP。
- 測定はTRピーク（窓内で最も熱い1本）。持続性は別軸。
